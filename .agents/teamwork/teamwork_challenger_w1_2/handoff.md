## 2. Logic Chain

1. **Schema & Contract Conformance**:
   - The Flex bubbles generated by `buildAttendanceDailyFlex` and `buildTruckDailyFlex` were analyzed against LINE's Flex Message schema:
     - Outer container is type `'flex'` with valid `altText`.
     - Container is `'bubble'` of size `'mega'`.
     - Header colors strictly match `#003566` (Attendance Deep Navy) and `#0F2942` (Truck Slate-Navy) with `#D97706` (Signal Amber) accents, satisfying R3 and R4.
     - All child boxes specify valid layouts (`horizontal`, `vertical`).
     - All color codes conform to `#RRGGBB` format.
     - All text nodes have defined string values; zero empty string nodes in standard paths.

2. **Currency & Boundary Handling**:
   - Tested 0 staff and 0 trucks: generated bubbles remain structurally valid, formatting 0.00 THB cleanly without dangling commas, NaN, or broken layouts.
   - Tested negative net payroll (-2,500.00 THB): formatted correctly as `"-2,500.00 บาท"`.
   - Tested large integer satang (up to 54,321,098.76 THB): formatted correctly with thousands separators.
   - Tested special characters (`&`, `<`, `>`, `"`, `'`, `/`, `[ ]`, `#`, `+`, `%`, Thai script): serialized safely without JSON encoding corruption.

3. **Configuration Fallback Hierarchy**:
   - Tested full precedence:
     `Firestore doc profile/line` > `Environment variables` > `Internal defaults`.
   - Confirmed `LINE_NOT_CONFIGURED` exception is thrown if `channelAccessToken` is missing or whitespace-only.
   - Confirmed Firestore exceptions are safely caught and fall back to environment variables.

4. **Routing Verification**:
   - Verified that when `targetId` is provided, `sendLinePush` dispatches HTTP POST to `https://api.line.me/v2/bot/message/push` with `{ to: targetId, messages }`.
   - Verified that when `targetId` is undefined, empty, or whitespace, `sendLinePush` dispatches HTTP POST to `https://api.line.me/v2/bot/message/broadcast` with `{ messages }` (omitting `to`).
   - Verified that `resolveTargetId` correctly prioritizes scope-specific target IDs before falling back to `defaultTargetId`.

## 3. Caveats

1. **External Network Calls**:
   - Verification was executed using Node's standard `fetch` contract intercepted in-memory with exact URL, header, and payload validation. Live network requests to LINE servers require active production credentials.
2. **Advisories for Future Enhancements (Non-Blocking)**:
   - **Advisory 1 (altText truncation)**: In `src/lib/line/flex-templates.ts`, `altText` concatenates `data.shopName`. If a shop name exceeds ~350 characters, `altText` could exceed 400 characters. A defensive `.slice(0, 400)` on `altText` would prevent potential HTTP 400 errors from LINE API.
   - **Advisory 2 (Box component pagination)**: If a shop ever has >95 staff with special deductions on a single day, the body box contents would exceed LINE's 100 components limit. Truncating at e.g. 30 special staff with a summary indicator "+ อีก N รายการ" would guarantee safety for arbitrarily large organizations.
